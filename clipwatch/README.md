# clipwatch

思路就是开一个终端窗口(terminal),跑一个很 lightweight 的 Python 脚本。然后你复制什么,它就自动把那段文字追加到一个笔记文件里。

整个 flow 都在本地。启动的时候给它一个名字,比如「读书笔记」,它就在固定文件夹里建一个同名文件。之后复制的东西全写到这里,每次复制用一个时间戳隔开。不管你从哪里复制,网页、微信、ChatGPT 之类的,只要是文字、能进剪贴板就行。写完关掉,下次用同一个名字就接着写,换个名字就是新文件。

## 怎么跑(Mac)

1. 把 `clipwatch.py` 存到桌面。
2. 打开终端,粘贴回车:

   ```
   python3 ~/Desktop/clipwatch.py 读书笔记
   ```

   第一次可能弹窗装「命令行开发者工具」,装完再跑一次。

3. 复制东西,终端每次打印「记下 N 字」。用完 Ctrl+C。笔记在桌面 `clipwatch` 文件夹里。

不写名字默认叫 `inbox`。Windows / Linux 也能跑,Linux 先装 `xclip`。

## 限制

- 微信不让全选,只能手动选中复制。
- 有些 app 复制太长会被截断,比如 ChatGPT,长的也得手动选中分段复制。
